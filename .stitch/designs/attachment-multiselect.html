Architectural Directives & Engineering Rules

Formal contracts governing keyboard interactions, disambiguation invariants, and thread boundary management.

keyboard

1. Keyboard & Focus Contract

  • • Ctrl/Cmd+Click: Toggles discrete individual entity in/out of active set.
  • • Shift+Click: Contiguous range selection across visible grid index from last focused anchor.
  • • Ctrl/Cmd+A: Selects visible eligible items only when gallery has focus; input search retains standard text editing.
  • • Escape 2-Stage: First stroke purges selection set; second stroke dismisses dialog window.
FOCUS_TARGET: GalleryItemGrid
tag

2. Entity Disambiguation

  • • Immutable Short IDs: Files are uniquely identified by hex short IDs (#f01, #f08).
  • • Zero Name Collision: Two identical filenames like "Project overview.pdf" coexist without overwrite risk.
  • • State Mapping: Selection sets store array of IDs: ['#f01', '#f08'] never string filenames.
PRIMARY_KEY: vault_item_uuid
security

3. Pending & Destructive Safety

  • • In-flight Exclusion: Items with stage STAGE_ENCRYPTING are disabled from selection sets to avert chunk corruption.
  • • Locked Checkbox: Hover on disabled item presents tooltip: "Pending attachments cannot be selected".
  • • Explicit Confirmation: "Remove selected" requires secondary inline tap verifying count before deleting SQLite records.
GUARD: assertNotPending(item)
devices

4. Platform Ergonomics & Parity

  • • Desktop First: Direct click on checkboxes, continuous marquee drag selection, and multi-key modifiers.
  • • Mobile Bridge: Maps 1:1 to Flutter mobile long-press bottom modal sheet while leveraging desktop pointer accuracy.
  • • Native File-Picker: Add button invokes OS native multi-file dialogue without re-implementing OS chrome.
PARITY: Flutter MultiSelectController
