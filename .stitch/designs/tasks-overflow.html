Architectural Directives & UX Guarantees

01

Universal Overflow Entry (pending_actions)

Standardizing background task inspection inside the three-dot (more_vert) menu across both notes list and note editor views on mobile and desktop. Idle state shows clean label with icon; active state appends counter badge (1).

Material Spec Icon pending_actions
02

Elimination of Standalone Badges

Stripping out standalone sync/pause/bell icons in chrome headers to prevent visual noise and preserve standard OS titlebar hierarchy. Active job counts appear next to the menu entry only, never as a detached header button or badge.

Header Chrome Policy Zero Standalone Badges
03

Interrupted Task Policy

Zero spinners or progress bars for interrupted items; remaining accessible strictly for Review and Dismiss without falsely signaling active work or inflating the running counter badge.

Interrupted State Review / Dismiss Only
