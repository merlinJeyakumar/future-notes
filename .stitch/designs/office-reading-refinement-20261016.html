Project overview

description

Future Notes provides high-efficiency local document caching and offline note composition. This specification details local buffer boundaries, cryptographic container encapsulation, and desktop operating system minimization ergonomics.

All attachments are bound to localized encrypted block nodes without external cloud transmission. Read-only sandboxing prevents script execution inside embedded documents, ensuring isolation across document previews.
