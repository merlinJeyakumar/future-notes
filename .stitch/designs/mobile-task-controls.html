Architectural Directives & UX Guarantees

01

48dp Chevron Formatting Disclosure

Accessible icon button (expand_more / expand_less) completely supersedes legacy text labels. Toggling executes inline within the normal document flow directly above the editor canvas, eliminating modal viewport collisions and keyboard overlap.

WCAG 2.1 Target Size 48 × 48 dp verified
02

Code-First HTML Source View

Continuous line numbered gutter coupled with preserved two-space indentation. Long element definitions are strictly preserved via horizontal scrolling (overflow-x-auto) rather than forced soft-wrapping to retain structural code legibility during mobile debugging.

Prettier AST Normalizer Explicit 'Format HTML'
03

Active vs. Interrupted Task Telemetry

Top bar sync badge strictly counts only executing workloads (value: 1). Interrupted tasks suppress all indeterminate spinners, progress bars, and progress percentages—rendering only actionable Review and Dismiss touch controls.

Worker Queue Filter State: EXECUTING_ONLY
